# Integrations

This directory keeps adapter boundaries for existing AI projects. The portal and gateway should depend on adapter contracts, not on each project's internal implementation details.

## Phase 1 Adapters

- `inkos-adapter`: AI 小说创作入口和后续项目/章节 API 适配。
- `toonflow-adapter`: Toonflow-web 与 Toonflow-app 的任务创建、状态查询和输出归档适配。
- `xhs-adapter`: XHS_ALL_IN_ONE 后期接入占位。
- `moneyprinter-adapter`: MoneyPrinterTurbo 后期接入占位。
